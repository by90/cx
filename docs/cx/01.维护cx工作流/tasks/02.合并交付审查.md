# 任务 02：合并交付审查

## 来源

- 用例文件：`../00.用例.md`
- 设计文件：`../00.设计.md`
- 对应用例路径：主成功场景第 5 步

## 目标

让 `$cx-review` 在一个技能内连续完成交付物质量审查和完成证据门禁。

## 文件范围

- 主要入口：`SKILLS/zh/cx-review/SKILL.md`
- 单元测试文件：未声明

## 任务量具

- 规则组：交付物分类审查、验证证据、缺失证据、完成状态、剩余风险

## 当前实现要求

- `$cx-review` 是唯一交付审查入口。
- 第一阶段审查交付物质量，第二阶段审查完成证据。
- 任一审查阶段失败时，任务保持未完成，临时变更文件不得删除。
- 机器学习实验审查直接核对项目正式版本标签和冻结产物、训练前联网研究、同口径业务指标，以及每个结论所依赖训练至少二十一次验证损失严格改进的证据资格。
- 不足二十一次严格改进的训练只能作为无效事实保存，不得进入方向判断、候选晋级、剪枝、参数重要性、最优候选或扩容结论。

## 验证方式

- 校验技能集合和包清单只有一个交付审查入口。
- 以机器学习实验交付物核对正式基线、研究笔记、验证损失改进计数和无效证据隔离规则。
- 使用 `$cx-review` 输出统一审查结论。

## 状态

- 统一审查：通过
- 当前状态：完成
- 执行模式：用户明确要求连续推进全部任务
