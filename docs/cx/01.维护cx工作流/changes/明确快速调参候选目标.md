# 变更：明确快速调参候选目标

## 状态

## 当前事实

- `$cx-pytorch-quick-hpo` 已要求轻量阶段选择数据参数、模型结构参数和训练参数。
- 当前技能按固定阶段搜索字段、窗口、训练参数和模型结构，未明确要求跳过用户已经固定的特征或参数。
- 当前候选规则先评价训练可持续性，再比较损失和回测，容易被理解为只按某一类指标筛选候选。

## 目标状态

- 快速调参覆盖所有未被用户固定且会影响目标结果的重要维度，包括模型结构、学习率范围、优化器、调度器和滑动窗口长度等样本特性。
- 用户明确固定的特征或参数保持不变，不进入搜索空间；固定一个维度不应连带冻结其它未指定维度。
- 最终 `5` 个候选以四项联合目标为最高优先级：`val_loss` 较小、`val_loss` 改进较多、尽量跑满 `120` 个训练轮次、最佳轮次尽量靠后。
- `test_loss`、回测结果、训练速度和资源利用率用于泛化确认、业务确认或执行约束，不得替代四项联合目标。

## 主要变化

1. 增加调参范围清单，逐项区分用户固定、参与搜索和有证据排除的维度。
2. 明确模型结构、学习率范围、优化器、调度器和滑动窗口长度属于默认必须考虑的调参维度。
3. 把最终五候选的四项联合目标提升为技能的最高优先级判定，禁止按单一指标选出五候选。
4. 先更新中文技能源和中文安装包镜像，再同步英文源、英文安装包和公开说明。
