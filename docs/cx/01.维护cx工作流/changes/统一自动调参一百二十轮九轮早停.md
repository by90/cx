# 统一自动调参一百二十轮九轮早停

## 当前问题

`cx-pytorch-hpo` 把普通单候选的 `120/9` 规则排除在正式自动调参之外，并要求正式参数试验关闭训练早停、只由剪枝器决定实际轮数。该规则会让仍有微小改善的参数试验被固定最小提高幅度误停，也会让已经连续九轮没有任何改善的参数试验继续浪费训练时间。

## 当前要求

1. 普通单候选和正式自动调参参数试验都最多训练一百二十轮。
2. 两类训练都以项目明确的验证选择目标执行九轮早停。
3. 只要验证选择目标产生任何严格提高，忍耐计数立即归零，不设置最低提高幅度。
4. 剪枝器可以在九轮早停之前淘汰相对劣势参数试验，但不得取消、替代或延长 `120/9` 规则。
5. 删除中英文技能、安装包镜像、设计和固定任务中的冲突说法。
6. 先完成中文源和中文包，再同步英文源和英文包。

## 顺序工作清单

1. 修改当前设计和原任务文档中的自动调参停止规则。
2. 修改中文 `cx-pytorch-hpo` 技能源并同步中文安装包镜像。
3. 同步英文技能源和英文安装包镜像。
4. 执行双语包验证、单一来源校验和统一交付审查。
5. 审查通过后删除本变更文件，提交并推送 `main`，再从远端安装中文包。
