## 当前事实

`cx-pytorch-hpo` 规定正式自动超参数优化关闭框架人工早停，并由剪枝器根据逐轮验证业务指标决定每次参数试验的实际轮数。当前规则没有说明普通单候选实验的最大轮数、早停忍耐和训练不畅判定。

## 目标状态

普通单候选实验默认最多训练一百二十轮，不设置必须完成一百轮的最低门槛。验证选择目标连续九轮没有改善时提前停止，并明确判定该候选训练不畅。正式自动超参数优化继续由剪枝器决定停止，不把固定忍耐重复叠加到参数试验。

## 主要变化

1. 在中英文 `cx-pytorch-hpo` 技能源和安装包镜像中增加普通单候选实验的 `120/9` 停止规则。
2. 明确连续九轮无改善是训练不畅判定，不是必须先完成一百轮后的附加条件。
3. 保留正式自动超参数优化关闭框架人工早停、由剪枝器决定实际轮数的当前规则。
4. 更新当前设计与原任务，使正式文档只表达最新规则。
