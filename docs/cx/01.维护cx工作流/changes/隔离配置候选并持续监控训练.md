# 变更：隔离配置候选并持续监控训练

## 当前事实

- 全局规则尚未明确区分配置候选值与配置解析、类型、传递和冻结行为。
- `$cx-pytorch-hpo` 已禁止参数试验改写产品默认配置，但尚未明确允许参数试验使用独立临时配置文件，也未说明产品默认配置服务于正式版推理。
- 当前训练报告只统一要求动态 TopN、固定 Top1、Top3 和 Top10，缺少固定 Top5，也没有要求人工智能代理逐轮持续读取并报告最高三级命中率与最低三级混入率。
- `$cx-timeseries-modeling` 与 `$cx-review` 尚未完整覆盖上述配置隔离和逐轮监控合同。

## 目标状态

1. 仅修改学习率、权重衰减、批量、调度参数等实验候选值时，不创建或修改单元测试，不把具体候选值固定在断言中。
2. 配置解析、类型、传递或冻结行为发生变化时，只在用户、当前任务或当前变更明确声明单元测试后验证行为。
3. 参数试验优先复制类型化配置并在内存覆盖，也可以读取本次试验独有的临时配置文件；两种方式都不得修改服务于正式版推理的产品默认配置。
4. 每个完整训练轮结束后，人工智能代理持续读取真实训练轨迹并报告轮次、耗时秒数、早停计数、验证损失和训练损失。
5. 股票排名训练每轮分别报告最高三级命中率和最低三级混入率，两组都使用动态 TopN、固定 Top1、Top3、Top5、Top10 的同口径顺序。
6. `$cx-review` 把配置隔离、实际生效配置快照和逐轮监控完整性纳入机器学习实验审查与完成证据门禁。
